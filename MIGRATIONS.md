# Migration Notes

Version-specific checks for updating an already framework-managed workspace across framework versions that changed operating guidance, templates, or optional tools. Not a permanent setup checklist — a fresh install applies none of it. For the update procedure, use `framework/SKILLS/update-framework/SKILL.md`.

Each version that demands migration has its own file, listed below. Read every indexed version above the workspace's installed `framework/CURRENT_VERSION` up to and including the target `framework/VERSION`; the installed version's own file was applied when the workspace reached it. A version absent from the index demands no migration — that absence is the answer, so do not look for a file that is not listed.

If `CURRENT_VERSION` is missing, the installed version is unknown. Resolve it with the Operator rather than inferring a range.
