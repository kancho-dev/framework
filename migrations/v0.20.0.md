# v0.20.0 — Role Selection From The Next Action And `/no-context`

This release makes `FRAMEWORK.md` resolve role selection for task sessions, gives the task-browser metadata CLI its own reference file, adds an optional `/no-context` command template for bounded work that should not load framework context, and promotes the optional Tokens / Cost Analyzer.

Most framework-side changes need no workspace action; they live entirely inside `framework/`, which an update replaces wholesale. The new command template needs a decision because prompt installation is per-file, and analyzer access through Cockpit needs a decision because that local-data tool remains explicitly opt-in.

## Required checks

1. If optional native command prompts are **symlinked selectively**, add a symlink for `framework/prompts/no-context.md` when the `/no-context` command should be available locally. A per-file symlink loop does not pick up prompts added by later releases.
2. If optional native command prompts were **copied** instead of symlinked, re-copy `framework/prompts/` when the Operator wants `/no-context` available. Copies never auto-update.
3. If neither applies, no action is needed; the workspace simply has no `/no-context` command.

## Optional checks

4. `/no-context` instructs a run to read no framework files, select no role, and write no framework-managed state. Confirm this is acceptable for the workspace before installing it. It governs agent behavior, not tool autoload: a tool that always loads `AGENTS.md` or `CLAUDE.md` will still have loaded them.
5. Task-browser metadata CLI documentation moved from `tools/task-browser/README.md` into `tools/task-browser/METADATA-CLI.md`. The README keeps a pointer, so existing references still resolve. Update workspace-local docs or custom skills that cite the old location only if a direct link is preferred.
6. The Tokens / Cost Analyzer is now documented as an optional alpha tool. Its standalone `npm start` path needs no workspace config. To expose it through Cockpit, explicitly set `tools["tokens-cost-analyzer"]` to `true` for each selected workspace in `.tools-config/tool-orchestrator/workspaces.json` (or the file named by `TOOL_ORCHESTRATOR_WORKSPACES_CONFIG`). Keep generated analyzer reports and local pricing/subscription state under the ignored `.tools-config/tokens-cost-analyzer/` path.

## Not required

- No change to the workspace `AGENTS.md`. The v0.18.0 boundary still applies; if it was merged then, nothing further is needed now.
- No task, project, state, or metadata migration.
- No action for the `FRAMEWORK.md` read-order and role-selection changes. They are inherited with the framework update.
- Workspaces that use no command templates need do nothing for this release.
